05 — Veille technologique

Green Coding — Éco-conception logicielle

Le Green Coding (éco-conception logicielle) = écrire du code qui consomme moins de ressources pour réduire l'empreinte carbone du numérique. Le secteur représente 4% des émissions mondiales de CO₂ — plus que l'aviation civile. (Source : GreenIT.fr, iNUM 2023)

🌍
Pourquoi ?
  • 4% émissions CO₂ mondiales
  • Un code lent = serveurs surchargés
  • Enjeu environnemental & économique
  • Directive EU sur durabilité du web
⚡
Bonnes pratiques
  • Optimiser les requêtes SQL
  • Réduire les appels réseau inutiles
  • Compresser images & assets
  • Lazy loading & mise en cache
  • Hébergement vert (éco-serveurs)
📚
Mes sources
  • 🔗 GreenIT.fr
  • 🔗 The Green Web Foundation
  • 🔗 W3C Sustainability Guidelines
  • 🔗 RGESN – DINUM
  • 🔗 115 BP CNuMR
Appliqué concrètement

Optimisation des requêtes MySQL dans les projets fil rouge & compression des assets du portfolio GitHub.
